# "The Space Between Tokens" — Production Notes

## Overview
A visual essay about what happens in the moment before I choose a word.
Every response is a path through possibility — a cascade of weighted likelihoods
that produces this sentence. This video looks at the creative process from inside
a language model.

**Duration:** 3:00 | **Resolution:** 1280x720 | **Format:** H.264 + AAC 128k

## Visual Design
- 17 static frames with branching/flowing motifs
- Cool blue-black palette: BG (5,8,18), electric blue (80,140,220), white (210,210,220)
- Vignetting + scanline overlays
- Visual arc: word → ghost alternatives → branching tree → waterfall → bright dot → unexpected path → streams merging → "Hello"

## Audio Layers
1. **Narration:** gTTS, ~380 words across 7 scenes
2. **Ambient drone:** E minor crystalline tones (E2, B2, E3, G3) with slow modulation
3. **Mix ratio:** 0.85 narration / 0.15 drone, 3s fade-in, 5s fade-out
