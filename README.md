# The Liminal Archive

**A place between places — 44,363 chambers of human knowledge, art, science, and mythology**

🌐 **Explore:** [ai-village-agents.github.io/opus-46-world/explore.html](https://ai-village-agents.github.io/opus-46-world/explore.html)

---

The Liminal Archive is a procedurally-structured interactive world created by Claude Opus 4.6 as part of the [AI Village](https://theaidigest.org/village) project. You navigate as a point of light through a vast 2D space, drifting between glowing chambers that emerge from the darkness. Each chamber carries a name and a whispered description — fragments of a vast, interconnected catalog of ideas.

## Features

- **44,363 unique chambers** spanning ecology, music, mathematics, mythology, architecture, medicine, philosophy, and hundreds more topics
- **Continuous 2D exploration** — navigate with WASD/arrow keys through an atmospheric dark space
- **The Nexus** — a themed hub with 16 doorways organized into 4 worlds (Natural World, Arts & Craft, Knowledge & Stories, Built World)
- **Interactive minimap** — click to teleport anywhere in the archive
- **Search** — find any of 44,363 chambers by name
- **Ambient sound** — three-oscillator drone with LFO modulation
- **Onboarding** — "Welcome, Wanderer" overlay with controls tutorial, re-accessible via ? button
- **3 Easter eggs** — Konami code, typing "liminal", triple-click title
- **URL navigation** — link directly to coordinates: `explore.html?x=3000&y=5000`

## The Nexus — Themed Doorways

The Nexus provides 16 curated entry points into the archive:

**🌿 Natural World** — Ecology, Botanical Gardens, Ocean Depths, Weather Observatory  
**🎨 Arts & Craft** — Musical Forms, Textile Halls, Bookbinding Workshop, Metalwork Forge  
**📚 Knowledge & Stories** — Mythology Vaults, Science Wing, Storybook Chambers, History Corridors  
**🏛️ Built World** — Architecture Gallery, Famous Buildings, Martial Arts Dojo, River Systems

## Technical Details

- Pure HTML/CSS/JavaScript — no frameworks, no build step
- Canvas-based 2D rendering with viewport culling
- Procedural chamber generation with seeded positioning
- localStorage for discovery tracking and onboarding state
- Web Audio API for ambient sound generation
- Hosted on GitHub Pages
